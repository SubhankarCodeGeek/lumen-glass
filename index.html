The material

Beyond blur. Into optics.

A blurred translucent panel averages the pixels behind it. Glass bends them. Lumen Glass samples the backdrop at a displaced coordinate derived from a signed distance field, then grades the result.

  • Refraction

    The sample point is displaced toward the surface centre along the boundary normal, scaled by the smaller half-extent — so a wide banner bends like a square card.

  • Chromatic dispersion

    Red, green and blue are sampled at radial scales of 1 + d, 1 and 1 - d, so the colour fringe is zero at the optical centre and grows toward the rim.

  • Rim profiles

    TORIC, SMOOTH, DROPLET and LEGACY change how the rim-weighted displacement ramps from the flat core to the perimeter.

  • Lighting

    A hairline perimeter stroke plus a directional specular lobe, so the contour stays defined instead of going black on the side facing away from the light.

  • Frost and tint

    Platform blur, a saturation and contrast grade, and a material tint — the difference between water, smoked glass and frosted acrylic.

Capabilities

What the library actually does

Every item below maps to code in the library/ module — a clean-room optical core, an Android rendering layer, and a Compose surface on top.

Custom AGSL shaders

The advanced path is an AGSL RuntimeShader built once and applied through RenderEffect, so the glass is evaluated on the GPU instead of being approximated with stacked Android views.

Optical refraction

Background content is sampled at a coordinate displaced by a rounded-rect SDF and its boundary normal, so the surface behaves like a lens rather than a cut-out.

Configurable rim profiles

Four geometric profiles — TORIC lens arc, SMOOTH quadratic fillet, DROPLET bipolar meniscus and LEGACY radial field — selected with one enum.

Chromatic dispersion

Per-channel radial scaling in the shader splits wavelengths toward the rim. It is the most expensive effect, so it only runs on the HIGH tier — one sample is used everywhere else.

Glass lighting

A 360° hairline stroke, a top-left specular lobe, a Fresnel sheen inside the edge, and an optional bezel inner shadow on the HIGH tier.

Jetpack Compose API

LumenSource, Modifier.lumenGlass and rememberLumenGlassState, configured through a typed GlassSpecBuilder DSL whose defaults are already sensible.

Adaptive rendering

QualityTier resolves to explicit feature flags you can read back through resolvedFeatures. Below API 33 the surface draws a deliberate frosted panel rather than nothing.

Rim profiles

Four edge treatments, one API

A profile changes only how the rim-weighted displacement ramps between the flat interior and the perimeter. The lens weights, lighting and grading are shared. Select one to compare:

Toric meniscus

RimProfile.TORIC default

A circular lens arc. The slope is zero at the interior boundary, so the flat core joins seamlessly, and near-vertical at the perimeter, which produces the strongest magnification of the four.

curve(u) = 1 - sqrt(1 - u*u) offset = -normal * (curve * maxDisp)

Smooth bevel

RimProfile.SMOOTH

A progressive quadratic fillet. Magnification builds gradually and there is no slope discontinuity at either end, which suits control sheets and status overlays where a hard rim would read as an artefact.

curve(u) = 0.30 * u + 0.70 * (u*u) offset = -normal * (curve * maxDisp)

Liquid droplet

RimProfile.DROPLET

An outward bulge subtracted from the inward zoom, so the displacement changes sign partway across the rim: content swells before it is drawn under the edge.

bulge(u) = sin(pi * u) * 0.35 zoom(u) = 1 - sqrt(1 - u*u) offset = normal * bulge*maxDisp - normal * zoom*maxDisp

Legacy field

RimProfile.LEGACY

The original displacement, kept for comparison. It blends a radial term with the boundary normal using the superellipse field and adds no rim curvature of its own — the shape of the distortion is the surface SDF.

dir = mix(-n, -normal, sq*sq) offset = dir * weight * scale

Integration

Three steps to a glass surface

One state object is shared by the background capture and the material. The surface must overlap the captured region, or there is nothing to refract.

  1. Create the glass state

    The tier is chosen from the device capability. Pass an explicit QualityTier to override it — dispersion and the bezel only run on HIGH.

    GlassCard.kt 
    val glass = rememberLumenGlassState()

  2. Wrap the background

    LumenSource records its content into a graphics layer. Everything inside it becomes refractive material for every glass surface sharing this state.

    GlassCard.kt 
    LumenSource(state = glass, modifier = Modifier.fillMaxSize()) {
    FeedContent()
}

  3. Apply the material

    Modifier.lumenGlass samples that layer through the shader. Every property in the builder has a default, so this block is optional.

    GlassCard.kt 
    Box(
    Modifier
        .size(width = 340.dp, height = 200.dp)
        .lumenGlass(state = glass, cornerRadius = 28.dp) {
            refraction = 1.0f
            dispersion = 0.08f
            frost = 6.dp
            rimProfile = RimProfile.TORIC
        }
)

Installation

Add it in two blocks

Lumen Glass is published to JitPack straight from the GitHub repository. Current release: 0.1.1.

  • Add the JitPack repository to settings.gradle.kts.
  • Declare the dependency in your app module's build.gradle.kts.
  • Sync Gradle, then wrap your background in LumenSource.

Compatibility

Minimum SDK is 21. The AGSL shader pipeline requires API 33 (Android 13) or later; below that the library draws a frosted panel through the standard Android graphics APIs instead of failing.
