# Reference Assets & Apple Screenshots

Place original Apple screenshots, reference images, and UI captures in this directory (e.g., iOS Control Center, macOS Dock/sheets, visionOS glass materials).

These references serve as ground truth for:
- Refraction/specular highlight curvature and falloff
- Inner/outer border bevels and rim illumination
- Tint saturation and luminance preservation
- Shadow dispersion and background blur interaction
